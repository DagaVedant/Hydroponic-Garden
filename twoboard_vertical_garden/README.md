# twoboard_vertical_garden

the archived two-board electronics design: a Raspberry Pi 4B + custom hat, plus a separate Pico
"pumps" board talking over an isolated two-wire link. both boards are fully routed (0 DRC errors)
and have real gerbers/BOM pricing.

superseded by the single-board Pi 5 design now at the repo root -- see [../spec.md](../spec.md)'s
electronics section for why. kept here for reference, not for further work.

| | |
|---|---|
| `PCB/` | the hat and pumps kicad projects, gerbers, and fab scripts |
| `BOM.csv` | pricing for the two-board build (Digikey/Amazon/JLCPCB, real links) |
